[role="lead"]
Google Cloud NetApp Volumes NFS 및 SMB 공유를 제공하기 위해 여러 TCP 포트를 노출합니다.

* https://docs.cloud.google.com/netapp/volumes/docs/connect-clients/connect-nfs-clients#firewall_rules_for_nfs_volumes_access["NFS 액세스에 필요한 포트"^]
* https://docs.cloud.google.com/netapp/volumes/docs/connect-clients/connect-smb-clients#firewall_rules_for_smb_volumes_access["SMB 접속에 필요한 포트"^]


또한 SMB, Kerberos를 포함한 LDAP를 사용하는 NFS 및 이중 프로토콜 구성에는 Windows Active Directory 도메인에 대한 액세스가 필요합니다. Active Directory 연결은  https://docs.cloud.google.com/netapp/volumes/docs/configure-and-use/active-directory/create-ad-policy["구성됨"^]지역별로 설정해야 합니다. Active Directory 도메인 컨트롤러(DC)는  https://docs.microsoft.com/en-us/openspecs/windows_protocols/ms-adts/7fcdce70-5205-44d6-9c3a-260e616a2f04["DNS 기반 DC 검색"^]지정된 DNS 서버를 사용하여 식별됩니다. 반환된 DC 중 하나가 사용됩니다. Active Directory 사이트를 지정하여 사용 가능한 DC 목록을 제한할 수 있습니다.

Google Cloud NetApp Volumes는 https://docs.cloud.google.com/netapp/volumes/docs/plan-and-prepare/networking#configure_private_services_access["Google Cloud NetApp Volumes 온보딩"^] 동안 `gcloud compute address` 명령으로 할당된 CIDR 범위의 IP 주소를 사용하여 연결합니다. 이 CIDR을 소스 주소로 사용하여 Active Directory 도메인 컨트롤러에 대한 인바운드 방화벽을 구성할 수 있습니다.

Active Directory 도메인 컨트롤러는 다음 조건을 충족해야 합니다 https://docs.cloud.google.com/netapp/volumes/docs/plan-and-prepare/security-considerations["여기에 언급된 대로 Google Cloud NetApp Volumes CIDR에 포트를 노출합니다."^].
